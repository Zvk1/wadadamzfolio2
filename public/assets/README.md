# Public asset directory

Place approved site media in the category folders:

- `projects/<project-slug>/` for project screenshots and diagrams
- `ctf/<challenge-slug>/` for challenge screenshots and diagrams
- `certifications/<credential-slug>/` for badges and public certificate copies

For a file named `public/assets/projects/example/screenshot.webp`, use `/assets/projects/example/screenshot.webp` in site content. Keep private or unredacted source material outside `public/`. The current profile portraits remain directly under `public/`; see `CONTENT-GUIDE.md` in the project root.
